SORTEIO RESTAURANTE

Esta pasta contém a versão PWA do aplicativo.

Para instalar no Android:
1. Coloque estes arquivos em um endereço HTTPS (por exemplo, hospedagem de site).
2. Abra index.html pelo navegador nesse endereço.
3. No Chrome, use "Adicionar à tela inicial" ou "Instalar aplicativo".

O aplicativo sorteia até 6 pessoas de uma vez e distribui as Praças 1 a 6 sem repetir praça na mesma rodada.

Observação: abrir o HTML diretamente como arquivo não permite a instalação PWA em todos os navegadores. Para instalação como aplicativo, é necessário HTTPS.
